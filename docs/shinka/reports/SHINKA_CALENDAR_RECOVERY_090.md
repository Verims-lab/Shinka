## Implemented boundaries

- selected/month represent inspection. Private original retry data and a frozen pendingOperation view separately retain the write identity/date/revision/period/status. A recovery date no longer becomes selection or a saved marker.
- Day details use actual month starts/recorded intervals/predictions for the inspected day. RECOVERY_REQUIRED explicitly says record information is unverified, rather than claiming absence. New add/edit/delete and consent changes remain blocked while a previous operation is unresolved; ordinary inspection cannot clear or replace that intent.
- Read generations supersede obsolete month reads independently of account/operation lifetime. A day or month can be inspected during an in-flight check/continuation. Old-month replies cannot redirect the user, and confirmation projected in the original month triggers only a fresh read of the inspected month. Global server-pending metadata is separate from the cached month, preventing an old month snapshot from resurrecting the previous recovery notice. Owner/consent/session invalidation still hides all health/pending state synchronously and drops stale responses.
- A single concise TR/EN recovery notice names the original date independently from day details. Check status is read-only. Continue remains a separate explicit action, available only after matching safe status evidence; it rereads and preserves the original action ID/revision/payload and existing 20-second continuation budget. A rejected continuation retains the unresolved original intent. A verified server-future add/edit date does not offer continuation; deletion retains its existing legacy-future repair rule. Confirmed receipts clear recovery; a conflicting still-pending receipt retains the lock and original identity. No receipt cancellation, new health field, storage, native backend/service/schema or OAuth change.
- Calendar alone collapses the unused 44px ProfileLogoSlot flow footprint. Matched baseline samples measure the logo/title gap at approximately 92px; both engines measure the after-gap at 47.987–47.999px, a 47.8% reduction. The actual profile control remains in the same safe logo corner. Global artwork, logo, styles, Home, Pattern, onboarding and navigation 083 source are protected.
