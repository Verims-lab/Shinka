# 079 — Viewport-anchored bottom navigation

Buildmarker-079 / HC-078.0. Clean AydanTest fast-forwarded from 87371ac to origin/main 80cacdd before editing; trees matched. Only AydanTest delivery is authorized. No main write, PR, Base44 publication or live-data operation.

## Cause and correction

The previous shared footer was static in document flow. 078 measured its painted row and document-end space, but did not require a viewport-bottom position while content scrolled. The local 320x568 actual App baseline measured initial zero-inset nav bottoms of 656.66px on Home, 801.66px on Calendar and 804.77px on Pattern, beyond the viewport. Scrolling to the end brought them to approximately 568px. No arbitrary footer margin was found.

ProductNavigation now contains a fixed dock and a flow placeholder with its measured border-box height plus any occluded viewport region. The latter lets the last content scroll above a keyboard when only the visual viewport shrinks. A layout effect measures before paint; ResizeObserver observes the border box to follow font, wrapping, width and inset padding changes. Hidden retained tabs preserve their last measured reservation. ProductTabs' document scroll ownership and saved tab state remain intact. PageContainer did not own the product footer and needs no change.

The fixed dock aligns with the visible viewport. When its bottom differs from the layout viewport, VisualViewport resize/scroll metrics supply that measured occlusion, with window resize fallback. Only the unoccluded system inset remains below the painted bar. The inset is separate from internal control padding. Each unchanged icon/label group now has at least 12px above/below, the existing 4px gap and adaptive height. There is no hardcoded bar height or arbitrary bottom offset.

RouteMotion uses opacity-only entry for product destinations, including the shared You footer. A scoped CSS guard also prevents transforms whenever the route contains product navigation: verified completed users can render Home at /login or /onboarding without a pathname change. Other hierarchy motion, routing, state, authentication, labels, 20px icons, caption styling, colors and equal horizontal thirds are preserved. Local scroll margins account for the measured bar. The original global PNG is unchanged.
